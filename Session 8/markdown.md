# Responsive Design:

## Pillar - 1
- Fluid Layouts
A fluid layout uses relative units like percentages, rather than fixed units like pixels or points. This allows the layout to adapt to the screen size of the device.

## Pillar - 2
- Media Queries
Media queries are a CSS technique introduced in CSS3 that allows you to apply styles based on the characteristics of the device rendering the content, such as its width, height, orientation, and resolution. This enables developers to create responsive designs that adjust to different screen sizes and devices.

### pillar -3 
- Flexible Media
Flexible media refers to the practice of using CSS techniques to ensure that images, videos, and other media elements scale appropriately within a responsive layout. This can involve using relative units, max-width properties, and other CSS rules to ensure that media content remains visually appealing and functional across various devices and screen sizes. 

# Common Screen Sizes
- mobile: 320px -767px
- tablet: 768px - 1024px
- desktop: 1024px and above
