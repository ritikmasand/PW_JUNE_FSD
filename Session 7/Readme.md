### Position Property

- position: value
- values can be:
- Static
- relative
- absolute
- fixed
- sticky

### Position offsets

- Once an element has been positioned, css also provides you properties to move it
- top
- right
- bottom
- left
- Example:

```
   top: 30px - move 30px from top
   left:30px - move 30px from left
```
